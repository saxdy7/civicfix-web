# @civicfix/ui-web

shadcn/ui-shaped component primitives for the CivicFix website (`apps/web`), styled with CSS
Modules and the design tokens in `apps/web/src/app/globals.css`. **No Tailwind CSS** — see
[`../../spec/DESIGN.md`](../../spec/DESIGN.md).

Feature components (`IssueMap`, `ReportComposer`, `PhotoCapture`, `LocationPicker`,
`StatusTimeline`, `PriorityBadge`, `IssueClusterCard`, `AssignmentPanel`, `AuditFindingCard`)
are added here as each screen is implemented.
