# CivicFix Mobile

React Native + TypeScript (Expo) app for citizen reporting and field-worker assignments.
See [`../../spec/DESIGN.md`](../../spec/DESIGN.md) for screens and [`../../spec/ARCHITECTURE.md`](../../spec/ARCHITECTURE.md)
for the shared Clerk+Convex architecture.

## Local development

```bash
npm install
cp .env.example .env   # fill in Clerk & Convex values
npm start
```
